Proyecto actual · en desarrollo

Nova — un bot con rostro animado que piensa con Claude

Ver el código en GitHub ↗

Nova vive en una Guition ESP32‑4848S040: un panel táctil de 4" y 480×480 px con un ESP32‑S3 (16 MB de flash, 8 MB de PSRAM). Tiene dos ojos grandes que parpadean y miran alrededor, y una boca que se mueve mientras habla. Sus respuestas las genera la API de Claude.

Cada respuesta llega como salida estructurada, así que el propio modelo decide qué expresión poner. El firmware dibuja la cara en un lienzo en PSRAM a unos 30 fps y hace la petición HTTPS en una tarea de FreeRTOS en el otro núcleo, para que la animación de «pensando» nunca se congele. 

{
  "emocion": "feliz",
  "respuesta": "¡Claro! Te explico cómo funciona…"
}
  • 7emociones que Claude elige en cada respuesta
  • ~30fpsanimación en un lienzo en PSRAM
  • 2núcleos: uno anima, el otro habla con la API
  • 8turnos de memoria de conversación

Retos resueltos

  • Pantalla RGB ST7701S con el pinout de la placa y buffer en PSRAM OPI.
  • Driver mínimo propio para el táctil GT911.
  • Fuentes con tildes y ñ (U8g2) y texto paginado bajo el rostro.
  • Certificados raíz embebidos para hablar con la API por TLS.
  • Máquina de estados: inactivo, escuchando, pensando, hablando y dormido.

Lo que viene: voz

  • Micrófono I2S (INMP441) en los pines libres del conector.
  • Voz a texto (por ejemplo, Whisper) → Claude.
  • Texto a voz con amplificador I2S (MAX98357A) y altavoz.
  • La boca ya se anima mientras «habla»: solo falta el sonido.
